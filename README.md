Un juego como el tetris, pero en vez de hacer líneas, haces palabras.
Conocí la idea por Carykh (https://www.youtube.com/@carykh) y fue anteriormente inventado por Tetris y publicado con el nombre de Wordtris.

Cuantas más letras tenga la palabra que consigas, más puntos dará. Además, al lado del tablero, te aparecerá la definición de la palabra creada, obtenida mediante un escaneo de la página de esa palabra en la RAE. Si la palabra tiene varias acepciones o se puede escribir con la tilde en varios sitios escogerá solo una de ellas. Tarda un poco entre palabra y palabra porque tiene que realizar la "request".

Acepta conjugaciones.

El archivo principal es TetrisScrabble.py el resto se usaron durante el desarrollo para pruebas o para la creación de los diccionarios.

Requiere los paquetes pygame, bs4 y requests.
